# Charte Graphique - Portfolio Alexis POUPELIN

## 1. Identité Visuelle

### 1.1. Palette de Couleurs
- **Couleur Primaire**: #6D4CFF (Violet profond)
- **Couleur Secondaire**: #F5F5F5 (Gris clair)
- **Texte Principal**: #1A1A1A (Noir foncé)
- **Texte Secondaire**: #666666 (Gris moyen)
- **Texte Muet**: #999999 (Gris clair)

### 1.2. Typographie
- **Titres**: System UI, sans-serif (police moderne et lisible)
- **Corps de texte**: System UI, sans-serif (lecture confortable)
- **Code**: Consolas, Monaco, monospace (pour les balises kbd)

## 2. Design System

### 2.1. Éléments de Base
- **Bords arrondis**: 12px pour les cartes et éléments principaux
- **Bords carrés**: 4px pour les éléments secondaires
- **Ombres**: Effet de profondeur subtil avec des transitions fluides
- **Espacement**: Grille de 16px pour l'alignement cohérent

### 2.2. Hiérarchie Visuelle
- **Titres H1**: 2.5rem, gras, couleur primaire
- **Titres H2**: 1.75rem, gras, couleur principale
- **Texte Normal**: 1rem, ligne 1.6, couleur principale
- **Texte Muet**: 0.875rem, couleur grise moyenne

### 2.3. Éléments Interactifs
- **Boutons**: Style flat avec effet hover de translation
- **Liens**: Soulignés au survol
- **Cartes**: Effet de flottement au survol
- **Formulaires**: Bords arrondis avec bordures subtiles

## 3. Composants Principaux

### 3.1. Section Héro
- **Disposition**: Split screen (texte + image)
- **Effets**: Animations d'apparition (fadeInLeft/fadeInRight)
- **Image**: Ombre portée avec drop-shadow(0 4px 12px rgba(0, 0, 0, 0.1))
- **Balises (kbd)**: Fond violet avec texte blanc

### 3.2. Statistiques
- **Grille**: Grid responsive (auto-fit, minmax(220px, 1fr))
- **Cartes**: Bordure grise, ombre subtile, effet de soulignement au survol
- **Progress Bars**: Gradient violet, animation fluide

### 3.3. Projets Récents
- **Grille**: Grid responsive (auto-fit, minmax(280px, 1fr))
- **Cartes**: Effet de translation au survol
- **Liens**: Soulignés au survol

### 3.4. CTA Footer
- **Design**: Carte avec bordure, ombre, gradient de soulignement
- **Alignement**: Centre
- **Boutons**: Largeur minimale de 200px

### 3.5. Timeline Expérience
- **Ligne**: Ligne verticale violette
- **Marqueurs**: Cercles violets avec effet pulse pour le poste actuel
- **Cartes**: Bordure grise, ombre subtile

### 3.6. Pipeline Compétences
- **Design**: Pipeline horizontal avec connecteurs
- **Étapes**: Numérotation circulaire, effets au survol
- **Connecteurs**: Flèches violettes

## 4. Thème Système

### 4.1. Thème Clair
- **Fond**: #FFFFFF (Blanc)
- **Texte**: #1A1A1A (Noir foncé)
- **Bordures**: #E0E0E0 (Gris clair)

### 4.2. Thème Sombre
- **Fond**: #121212 (Noir foncé)
- **Texte**: #FFFFFF (Blanc)
- **Bordures**: #333333 (Gris foncé)

### 4.3. Transitions
- **Durée**: 0.3s pour tous les changements de couleur
- **Timing**: ease-in-out
- **Propriétés**: background-color, border-color, color, fill, stroke, box-shadow

## 5. Responsive Design

### 5.1. Mobile First
- **Breakpoint**: 768px
- **Layout**: Flexbox pour les sections principales
- **Grille**: Grid responsive avec adaptation automatique

### 5.2. Adaptations Spécifiques
- **Section Héro**: Stack vertical sur mobile
- **Statistiques**: Grille 2 colonnes sur mobile
- **CTA Footer**: Layout adaptatif pour les boutons

## 6. Animations et Effets

### 6.1. Animations d'Entrée
- **Hero**: fadeInLeft/fadeInRight
- **Statistiques**: fadeUp avec délais successifs
- **Cartes**: Hover avec translation et ombre

### 6.2. Effets Interactifs
- **Boutons**: Effet de pression et de translation
- **Cartes**: Effet de flottement au survol
- **Marqueurs**: Effet pulse pour le poste actuel

## 7. Accessibilité

### 7.1. Contraste
- Respect des ratios de contraste WCAG 2.1 AA minimum
- Texte lisible sur toutes les surfaces
- Indicateurs visuels clairs pour les interactions

### 7.2. Navigation
- Navigation au clavier complète
- Indicateurs visuels pour les éléments focus
- Structure sémantique HTML correcte
